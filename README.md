# Bluekeep

Bluekeep is a lightweight, local-first web vault application engineered to securely store sensitive notes, credentials, and secrets directly within the browser. 

### Key Features
* **Zero-Knowledge Architecture:** Data encryption and decryption occur entirely on the client side using the Web Crypto API.
* **AES-256-GCM Encryption:** High-grade symmetric encryption paired with authenticated data integrity.
* **Lightweight UI:** Built with pure HTML5, CSS3, and modern JavaScript for fast load times and zero dependencies.
